# 2048 - Enhanced Edition 🎮

A beautiful, fully-featured implementation of the classic 2048 puzzle game with modern design and enhanced features.

## 🌟 Features

### Core Gameplay
- Classic 2048 mechanics on a 4x4 grid
- Smooth tile merging and movement
- Win detection (reach 2048!)
- Game over detection
- Score tracking with best score persistence

### Enhanced Features
- **Undo Functionality** - Take back your last move
- **Dual Keyboard Controls** - Use Arrow Keys OR WASD
- **Touch/Swipe Support** - Full mobile support with swipe gestures
- **Best Score Tracking** - Persists across sessions using localStorage
- **Modern UI Design** - Beautiful gradient background with smooth animations
- **Fully Responsive** - Works perfectly on desktop, tablet, and mobile

## 🎯 How to Play

1. Open `index.html` in your web browser
2. Use **Arrow Keys** or **WASD** to move tiles
3. On mobile, **swipe** in any direction
4. When two tiles with the same number touch, they **merge into one**
5. Keep merging to reach the **2048 tile**!

## 🎨 Design Highlights

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No build process or dependencies required!

# Navigate to the directory
